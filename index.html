    Чтобы качалось сразу в foobar2000
    1. Настройки iPhone → Приложения → Safari → Загрузки.
    2. «Другое…» → «На iPhone» → папка foobar2000 → «Готово».
    3. Открывай эту страницу именно в Safari (не с ярлыка на экране «Домой»).
    4. Жмёшь «Скачать» → файл ложится в папку foobar, трек сразу в библиотеке. Если не появился — в foobar: Settings → Media Library → Rescan.
