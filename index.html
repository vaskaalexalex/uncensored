    Чтобы качалось сразу в foobar2000
    1. Настройки iPhone → Приложения → Safari → Загрузки.
    2. «Другое…» → «На iPhone» → папка foobar2000 → «Готово».
    3. Открывай эту страницу именно в Safari (не с ярлыка на экране «Домой»).
    4. Когда трек готов, загрузка стартует сама и файл ложится в папку foobar. Если Safari спросит «Загрузить?» — жми «Загрузить». Если трек не появился в библиотеке — в foobar: Settings → Media Library → Rescan.
